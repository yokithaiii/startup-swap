# StartupSwap — Web Application

Веб-приложение маркетплейса StartupSwap. Представляет собой публичную часть платформы, личный кабинет пользователя и административный интерфейс.

## Публичная часть

Включает главную страницу, каталог проектов с расширенной фильтрацией, детальные страницы листингов с метриками и графиками выручки, страницы продавца, калькулятор оценки стоимости проекта, а также информационные разделы: как это работает, FAQ, условия использования, политика конфиденциальности.

## Личный кабинет

Доступен авторизованным пользователям. Содержит следующие разделы:

- Обзор — сводная статистика активности пользователя.
- Мои проекты — управление листингами: создание, редактирование, публикация, снятие с публикации.
- Избранное — сохранённые проекты с переключением между табличным и карточным видом.
- Сообщения — встроенный мессенджер с поддержкой реального времени через Supabase Realtime.
- Офферы — входящие и исходящие предложения о покупке с возможностью принятия, отклонения и отзыва.
- Сделки — отслеживание прогресса активных сделок по этапам.
- Настройки — управление профилем пользователя.
- Профиль пользователя — публичная страница продавца с активными проектами и статистикой.

## Создание листинга

Процесс размещения проекта разбит на шесть последовательных шагов: основная информация, технологический стек, метрики, медиаматериалы, ценообразование, предварительный просмотр и публикация.

## Аутентификация

Поддерживается вход по электронной почте и через GitHub OAuth. Защита маршрутов реализована на уровне middleware — неавторизованные пользователи перенаправляются на страницу входа с сохранением целевого адреса.
